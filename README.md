# Gravity Darkening in Exoplanet Transits

A Python-based Astrophysics research project investigating whether gravity-darkened transit photometry can constrain the true three-dimensional spin–orbit geometry of the hot Jupiter system **HAT-P-70.**

This repository contains the codes, analysis, and results developed during my MSc Astrophysics research project at University College London (UCL).

The project combines real TESS observations, statistical inference, and gravity-darkened transit modelling to investigate the orbital architecture of rapidly rotating exoplanet systems.

> **Status:** MSc Project completed (2026)
